# ตลาดจำลอง (mock market) — ซ้อมด่าน 3 บนเครื่องตัวเอง

ตลาดเมล็ดกาแฟจำลองที่รันบนโน้ตบุ๊ก **ไม่ต้องใช้ตลาดฝึก (8000) ตลาดแข่ง (8001) key หรือ LLM gateway**
API เหมือนของจริงทุก endpoint ใน `คู่มือ-API.md` · หน้าเว็บทีม `/trade` · จออันดับ `/leaderboard` · บอต 100 ทีม · LLM ปลอม
ใช้ Python มาตรฐานล้วน ไม่ต้อง `pip install` เพิ่ม

## เริ่มเล่นด่าน 3 (เหมือนวันที่ 20)

VS Code → Run and Debug (Ctrl+Shift+D) → **"ด่าน 3 จำลอง + Agent"** → ▶
(ต้องเปิดผ่าน `Coffee-TESA-starter.code-workspace`)

- เบราว์เซอร์เปิด **จออันดับ** และ **หน้าเว็บทีม** ให้เอง
- หน้าเว็บทีม: **พิมพ์ชื่อทีมได้เลย ไม่ต้องมี key** (ชื่อเดิม = ทีมเดิม)
- จออันดับ: กด **▶ Start ตลาด** → SETUP 10 นาที → ประเมิน 15 นาที → ซ้อม P1–P2 → จริง R1–R15 (รอบละ 6 นาที = เปิดรับ 5 + จับคู่ 1)
- **ไม่อยากรอ:** ปุ่ม "ข้ามช่วงนี้ ⏭" · ความเร็ว ×1…×60 · ติ๊ก "ข้ามเองเมื่อทุกทีมส่งครบ"
- ปฏิทินตามสไลด์: R1–5 ปกติ · **R6–8 เทศกาลกาแฟ** (ต้องการ ×1.4, Specialty 40%) · R9–12 ปกติ · R13–14 ใกล้ปิด (×0.7) · R15 รอบสุดท้าย (×0.45)
- จออันดับระหว่างแข่งมีแต่อันดับ และ **หยุดอัปเดตหลัง R12** เหมือนจริง · ติ๊ก "โหมดโค้ช" เพื่อดู PR/รายได้ทุกทีมสดๆ
- ล็อต 5 ล็อต 45 กระสอบ ทุกทีมได้โจทย์เดียวกัน (ค่าขยับเล็กน้อยต่อทีม) · เพดาน 5 กระสอบ/รอบ · ตัวอย่างคลาดจากของจริง

### ให้ agent ของเพื่อนมาแข่งด้วย

1. เปิดตลาดด้วย `--lan` (หรือเลือก "ด่าน 3 จำลอง (เปิดให้เพื่อนในวง Wi-Fi)") → จออันดับบอก `MARKET_URL=http://<IP เครื่องเรา>:9000`
   (Windows ถามเรื่อง Firewall ให้กด Allow)
2. เพื่อนเปิด `http://<IP>:9000/trade` พิมพ์ชื่อทีม → กล่อง "ให้ agent เล่นเป็นทีมนี้" มีค่า `.env` ให้ก๊อป
   (`MARKET_URL`, `TEAM_KEY`, `LLM_BASE_URL=http://<IP>:9000/llm/v1`) แล้วรัน agent ของเพื่อนตามปกติ
3. ปุ่มควบคุมตลาดกดได้เฉพาะเครื่องที่รันตลาด

`TEAM_KEY` เป็นอะไรก็ได้ (key ใหม่ = ทีมใหม่) · `run_agent.py` ไม่แตะ `.env` และเขียน log ที่ `mock-market/agent-logs/`
ไม่ปน `logs/` จริง · `pack.py` ข้ามโฟลเดอร์ `mock-market/` ทั้งโฟลเดอร์

## ห้องทดลองกลยุทธ์ (`benchmark.py`)

เล่นด่าน 3 จำลองแบบไม่ใช้เวลาจริง (เกมละ ~0.1 วิ) หลายสิบเกม ทุกกลยุทธ์เจอโลกเดียวกัน แล้วเทียบ PR

```bash
.venv/Scripts/python mock-market/benchmark.py --games 100                    # ทุกไฟล์ใน strategies/
.venv/Scripts/python mock-market/benchmark.py --games 100 v0_starter v4_combo
.venv/Scripts/python mock-market/benchmark.py --strategy-file strategy.py    # เทียบ strategy.py ที่กำลังแก้
.venv/Scripts/python mock-market/run_agent.py --strategy v4_combo            # เล่นสดในตลาดด้วยกลยุทธ์นั้น
```

ไฟล์ใน `strategies/` "สืบทอด" `strategy.py` ของทีม แล้วเขียนทับเฉพาะจุดที่ลอง (ดู `_base.py`):

| ไฟล์ | แนวคิด |
|---|---|
| `v0_starter` | starter ของทีมตามเดิม (เส้นฐาน) |
| `v1_margin` | เผื่อขอบสเปก: เมล็ดเสีย −0.6, ความชื้น −0.25 (กัน `SPEC_MISMATCH`) |
| `v2_calendar` | อ่านปฏิทิน: ขายตามความต้องการแต่ละรอบ เก็บล็อตเกรด Specialty ไว้รอเทศกาล ขายให้หมดก่อนช่วงท้าย |
| `v3_learn` | ปรับราคาต่อผู้ซื้อแต่ละราย สะสมทั้งเกม แล้วเลือก RFQ ที่ได้เงินมากสุดก่อน |
| `v4_combo` | v1 + v2 + v3 |
| `v5_high` / `v6_low` | starter แต่ราคา +5% / −4% (และขายเร็วขึ้น) |
| `v7_pressure` | ลดราคาเมื่อขายช้ากว่ากำหนด เรียนต่อประเภทสะสม เทของ 3 รอบท้าย |
| `v8_best` | v7 + v2 |

### ผลรอบล่าสุด (stage3, บอต 100, กฎล้วน, 100 เกม seed 8000–8099)

| กลยุทธ์ | PR (strategy.py รุ่นปรับแล้ว) | PR (strategy.py รุ่นแรก ตัวคูณ 1.00) | ค้างขายไม่ออก | สรุป |
|---|---|---|---|---|
| starter (v0) | 0.940 | 0.921 | 15% / 41% | รุ่นแรกโดน ABOVE_LIMIT 37% |
| **v4_combo** | **0.955** (ชนะ 73%) | **0.956** (ชนะ 91%) | 21% | **PR ดีสุด** ขายราคาดี (×0.98 TV) |
| v10_plus | 0.951 (ชนะ 67%) | 0.950 (ชนะ 82%) | 13–15% | ค้างน้อยกว่า อันดับเฉลี่ยดี ราคาต่ำกว่านิด |
| v7_pressure | 0.937 | 0.939 | 9–10% | ขายหมดเกือบหมดแต่ถูกไป (×0.945) |
| v6_low | 0.923 | – | 7% | ถูกไป ไม่คุ้ม |
| v5_high | 0.935 | – | 35% | แพงไป ค้างเยอะ |

**บทเรียน:** ขายให้หมดด้วยการลดราคาไม่ได้ช่วยเสมอ (v6, v7) · ตั้งแพงทั้งกระดานก็แย่ (v5) · ที่ได้ผลคือ **เผื่อขอบสเปก + ปรับราคา
สะสมต่อผู้ซื้อแต่ละราย + อ่านปฏิทิน** (v4) แล้วถ้าอยากลดของค้างให้เติม **ลดราคาเฉพาะล็อตที่มีแต่ Instant รับ + เทของ 3 รอบท้าย** (v10)
ประเมิน (`appraisal.py` เดิม): คลาดเฉลี่ย ~2% → ราว 15–17/20

ตัวเลขขึ้นกับค่าที่เดาในตลาดจำลอง (เพดานผู้ซื้อ, ความต้องการต่อเกรด `DEMAND_FACTOR`, นิสัยบอต) → ใช้เลือก "ทิศทาง" แล้วยืนยันกับตลาดฝึกจริง

### ทำไมบางเกม agent ขายได้น้อย

1. **กดข้ามเร็วเกินไป** — agent อ่านตลาดทุก ≤5 วิ และเรียก LLM อีก ~2 วิ ถ้ารอบจบใน 2–3 วิ agent จะพลาดรอบหรือส่งไม่ทัน
   (log: `ROUND_CLOSED`, `UNKNOWN_RFQ`) · ตลาดจำลองตอนนี้กันให้แล้ว: เปิดรับอย่างน้อย 20 วิ จับคู่อย่างน้อย 6 วิ และปุ่มข้าม
   รอให้ทุกทีมส่งก่อน (สูงสุด 15 วิ)
2. **ของเกรดต่ำล้นตลาด** — ทุกทีมได้ล็อตแบบเดียวกัน ล็อตที่มีแต่ Instant รับจึงแย่งกันหนัก ขายที่ 0.87 ยังดีกว่าค้าง 0.80

## preset อื่น

| preset | เหมือน |
|---|---|

`--show-secrets` (โชว์เพดานลับผู้ซื้อ) `--llm-fail-rate 0` `--llm-upstream http://localhost:11434/v1` · `--help` ดูทั้งหมด

## LLM gateway ปลอม (`/llm/v1`)

จำกัดเหมือนจริง (พร้อมกัน 2, 20 ครั้ง/นาที, max_tokens ≤ 2000, context 8,192) · อ่าน prompt ของ `strategy.py` แล้วตอบ JSON
แบบโมเดลตัวเล็ก · พัง 5% (500 / ช้า / JSON ขาด) ไว้ทดสอบทางสำรอง · **ตอนเร่งเวลา ×10 ขึ้นไป starter ข้าม LLM เอง
เพราะเวลาไม่พอ** (เหมือนจริงที่ต้องตอบทันรอบ)

## ต่างจากตลาดจริง

เพดานผู้ซื้อ ความคลาดของตัวอย่าง นิสัยบอต และสูตรคะแนนขาย (ที่นี่ PR สูงสุดในเกม = 80, PR 0.80 = 0 ตามสไลด์)
เป็นค่าที่ตั้งให้ใกล้เคียง ตลาดจริงไม่เปิดเผย · ปรับได้ใน `config.py`

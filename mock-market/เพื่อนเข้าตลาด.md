# เข้าตลาดจำลอง (ด่าน 3) จากเครื่องเพื่อน

เงื่อนไข: เครื่องเพื่อนต้องอยู่ **วง Wi-Fi เดียวกัน** กับเครื่องที่รันตลาด และเครื่องที่รันตลาดต้องเปิดด้วยโหมด
"ด่าน 3 จำลอง (เปิดให้เพื่อนในวง Wi-Fi)" (`--lan`)

## 0) แค่อยากดูแดชบอร์ด (ไม่ต้องพิมพ์ชื่อ ไม่ต้องใช้ key)
เปิด `http://<IP>:9000/leaderboard` ดูอันดับ ± รายรอบ PR รายได้ของทุกทีมได้เลย (กดปุ่มควบคุมตลาดได้เหมือนเจ้าของเครื่อง (Start, ข้าม, รีสตาร์ต, ความเร็ว) ถ้าไม่อยากให้กด เปิดตลาดด้วย --no-open-admin)

## 1) เข้าเว็บ
เปิดเบราว์เซอร์ไปที่ `http://<IP เครื่องที่รันตลาด>:9000/trade` (IP ดูได้จากหน้า `/leaderboard` ช่อง "เพื่อนในวง Wi-Fi")
- พิมพ์ **ชื่อทีม** (ไม่ต้องมี key) แล้วกดเข้า
- ชื่อทีมซ้ำกับของคนอื่น = ได้ทีมเดิมของคนนั้น ให้ตั้งชื่อไม่ซ้ำ
- ดูอันดับสด: `http://<IP>:9000/leaderboard`

## 2) ต่อ agent ของเพื่อนเข้ามา
หลังเข้าเว็บ หน้าจะมีบล็อก `.env` ให้คัดลอก ใส่ใน `.env` ของ agent:

```
MARKET_URL=http://<IP>:9000
TEAM_KEY=<key ที่หน้าเว็บให้>
USE_LLM=1
LLM_BASE_URL=http://<IP>:9000/llm/v1
LLM_MODEL=event-llm
LLM_API_KEY=<key เดียวกัน>
```
แล้วรัน `python main.py` ของ agent ตามปกติ ราคาเสนอโดย agent ของแต่ละทีมเอง

## 3) ถ้าเข้าไม่ได้
- เครื่องที่รันตลาด: Windows ถามเรื่อง Firewall ครั้งแรกให้กด **Allow** (ถ้าเผลอกดยกเลิก ให้เปิดพอร์ต 9000 ใน Windows Defender Firewall)
- เครื่องเพื่อนต้องใช้ Wi-Fi วงเดียวกัน (Wi-Fi แขกหรือบางมหาวิทยาลัยบล็อกการคุยกันระหว่างเครื่อง)
- ใช้ key เดิมหลังตลาดถูกรีสตาร์ต: key เก่าจะสร้างทีมใหม่ที่ไม่มีชื่อ ให้เข้าหน้า `/trade` พิมพ์ชื่อทีมใหม่แล้วใช้ key ชุดใหม่
